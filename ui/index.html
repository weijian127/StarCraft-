How to load a review

  1. Start a local server in the project root: python -m http.server 8000 --bind 127.0.0.1
  2. Open http://127.0.0.1:8000/ui/index.html?review=<directory>
  3. The review path is resolved from the server root, so runs/my-run/review works without a leading slash.

Demo directory: http://127.0.0.1:8000/ui/index.html?review=ui/demo/full
