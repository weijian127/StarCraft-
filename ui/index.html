    How to load a review

    1. Serve this page over HTTP from the same origin as the report.
    2. Open /ui/index.html?review=<directory>.
    3. The review path is resolved from the server root, so runs/my-run/review works without a leading slash.

    The bundled demo uses ?review=ui/demo/full on the same origin.
